About SPORTX

Built by players, for players

SPORTX started as a single counter stocking cricket bats and grew into an online store covering seven sports, run on the principle that good equipment should be easy to find and honestly described.

What we stock

Cricket, football, badminton, basketball, fitness, running and tennis — from entry-level kit to equipment club players use every week.

How we describe it

Every listing carries real specifications: weight, material, size and fit. If something runs small, the description says so.

Delivery and returns

Free shipping over ₹999, cash on delivery across India, and a seven-day return window on unused items in original packaging.

About this project

SPORTX is a full-stack web application built as a B.Tech Computer Science and Engineering project. The frontend is HTML5, CSS3 and vanilla JavaScript; the backend is Java Spring Boot exposing a REST API secured with JSON Web Tokens; data is stored in MySQL through Spring Data JPA. It demonstrates authentication, role-based authorisation, catalogue management, cart and stock handling, order processing and an admin dashboard.
