Frequently asked questions

The things customers ask most often.

How long does delivery take?

Orders placed before 2 PM ship the same working day. Metro cities usually receive their parcel in 2–3 days; other locations take 4–6 days.

Is cash on delivery available?

Yes, on every order across India. You can also pay online at checkout — in this project the online option uses a mock gateway, so no real payment is taken.

What is the return policy?

Unused items in original packaging can be returned within seven days of delivery. Personalised items and opened nutrition products are excluded.

How do coupons work?

Enter the code on the cart page. The discount applies to the subtotal after any product-level discount, provided your cart meets the minimum order value.

When is delivery free?

Shipping is free once the payable amount reaches ₹999. Below that a flat ₹49 delivery charge applies.

Can I cancel an order?

Yes, from your account page at any time before the order ships. Cancelling returns the items to stock automatically.

How do I know my size?

Shoe sizes follow standard UK sizing and apparel follows Indian sizing. Each product page lists the sizes in stock; if a size is missing, it has sold out.

Are my card details safe?

Passwords are stored as BCrypt hashes and the API is protected with JSON Web Tokens. The payment screen in this project is a demonstration and never collects real card data.
